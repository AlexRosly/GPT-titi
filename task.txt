🧠 Шаг 5. Память чата
Что делаем на этом шаге
✅ Краткосрочная память (STM)

последние N сообщений (например, 20)

используется в каждом запросе к модели

уже почти готово — мы её формировали в streamChat

✅ Долгосрочная память (LTM)

хранит важные факты о пользователе

НЕ отправляется целиком в каждый запрос

подмешивается как system-сообщение

обновляется асинхронно (не в стриме)

Для твоего GPT-проекта я бы сделал так:

Логин → получаем access token.
Socket подключается с ним.
Если сокет вернул Unauthorized → refresh → reconnect.
Все HTTP запросы через apiFetch.
Если API вернул 401 → refresh → повтор запроса.
Если refresh не удался → разлогиниваем пользователя и показываем экран входа.

Это стандартная схема для React/Next.js, Socket.IO и JWT.
